# Contributing

Thanks for your interest in MicroControl.

1. Open an issue describing the bug or improvement before large changes.
2. Include Android version, device model, board type and connection mode when relevant.
3. Do not include Wi-Fi credentials, keystores, tokens or personal data in issues or commits.
4. Keep README and validation documentation synchronized with code changes.
5. Run `./gradlew testDebugUnitTest assembleDebug` before opening a pull request when possible.
6. Test controller changes with real hardware and document the board firmware used.
